# Bundled color themes

Zed-format theme sets taken from
[gpui-component](https://github.com/longbridge/gpui-component/tree/main/themes)
(Apache-2.0), which in turn credits the original theme authors in each
file's `author` field. Written to `$XDG_DATA_HOME/picocode/themes/` at GUI
startup and loaded through gpui-component's `ThemeRegistry`.
